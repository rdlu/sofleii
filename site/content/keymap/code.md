Layer 2, held with `mo(CODE)` on the right thumb (position 60): brackets for
the left hand, and digraphs and snippets as one-key macros. Release the key
to go back to BASE.

{{< layer "CODE" >}}

## What's on it

- **Left home row**: `` ` `` · `{` · `}` · `[` · `]` · `+`. The `}` `[` `]`
  keys are mod-taps, Alt, Ctrl and Shift when held, like the home-row mods
  under them; they are plain `&mt` with ZMK's default timing.
- **Left bottom row**: `-` · `_` · `(` · `)` · `=`.
- **Left upper rows**: Elixir sigils (`~s()`, `~w()`, `~r//`, `~D[]`), `<>`,
  and the arrows `<-` `|>` `->` `=>`.
- **Right side**: `::`, `|_|`, `dbg!()`, `todo!()`, the turbofish `::<>`,
  bracket and quote pairs with the cursor left inside, the comparison
  operators `==` `!=` `<=` `>=`, and HEEx `{ }` and `<% %>`.
- **Delete**: the left-thumb Backspace position is `Del`, so CODE + Backspace
  deletes forward.

The macro legends in the grid are the text each macro types, read from its
definition in the keymap. The pipe operator `|>` is also a combo on BASE; see
[Combos](../combos/).
